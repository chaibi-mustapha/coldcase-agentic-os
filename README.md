## 📌 Executive Summary

Unresolved criminal cases remain cold for decades not because evidence is missing, but because **vital investigative links are fragmented across incompatible silos**:
- Sworn witness depositions given decades apart.
- Hardwired museum & bank vault sensor telemetry.
- Private Investigator field stakeouts & confidential dossiers.
- Microfilm scans of historical daily newspapers.
- Web sleuth & crowdsourced OSINT investigations (Reddit / Usenet).
- Multimodal documentary broadcasts & forensic wiretap audio tapes.

**ColdCase Detective AI** solves this challenge by deploying a team of **6 specialized autonomous AI agents** powered by **Google ADK & Gemini 3.7**, orchestrating multi-channel cross-correlation and rendering evidence onto an interactive **Hollywood-style Cinematic Crime Pinboard**.

## 🤖 The 6 Specialized Autonomous Agents

## ✨ Key Features & Innovation

### 1. 📌 Cinematic Hollywood-Style Crime Board ("Murder Board")
- **Realistic Corkboard Canvas**: HD ambient lighting, vintage texture, and realistic pushpins (red, brass, silver).
- **Rich Multi-Source Clue Cards**:
  - **Authentic Polaroids**: With scotch tape, realistic tilt, and handwritten forensic annotations (*Caveat* font).
  - **Forensic Sticky Notes**: Yellow and pink notes with curled corners for contradictions and Web Sleuth hints.
  - **Aged Newspaper Clippings**: Historical headlines (*Berliner Zeitung, Boston Globe, Wall Street Journal*).
  - **PI Confidential Reports**: Field surveillance files stamped `[ CONFIDENTIAL ]`.
  - **Audiovisual Video Cards**: Video thumbnails with timecodes and key testimony snippets.
- **Dynamic Catenary Red Strings**: SVG physical threads with drop-shadows and suspended investigation tags (*"Falsified Alibi"*, *"PI Stakeout"*, *"Titanium Particles"*).
- **Freeform Drag & Drop**: Freely reposition any Polaroid or note with real-time recalculation of the connecting red strings.
- **Channel Filters**: Filter instantly by *Private Investigators*, *Press Archives*, *Web Sleuths*, *Video Reports*, or *Police & DNA*.

### 2. 🎛️ 2-in-1 Unified Interactive Splitters (Resize & Toggle)
- **Mouse Drag Resizing**: Click and drag the splitter bars left or right to customize panel widths in real-time.
- **Quick-Toggle Pill (`◀ / ▶`)**: One-click instant collapse/expand of sidebars.
- **`⛶ MAX BOARD` Mode**: Expand the Crime Board to 100% fullscreen for maximum investigation immersion.

### 3. 🌐 Live Open Intelligence (OSINT) Integration
- Direct querying against Wikipedia Open REST API and FBI Wanted archives for real-time document and photo ingestion.

## 🚀 Quickstart Guide

### Prerequisites
- Python 3.10+ (tested on Python 3.11, 3.12, 3.13)
- Modern web browser (Chrome, Firefox, Edge, Safari)

### 1. Clone & Install
```bash
# Clone the repository
git clone https://github.com/votre-nom/coldcase-detective-ai.git
cd coldcase-detective-ai

# Install dependencies
pip install -r requirements.txt
```

### 2. Configuration
Copy `.env.example` to `.env` and set your Google Gemini API key:
```bash
cp .env.example .env
```
```env
GEMINI_API_KEY=your_gemini_api_key_here
MOCK_MODE=0  # Set to 1 for offline mock mode, 0 for live Google ADK agent execution
```

### 3. Launch the Investigation Console
```bash
# Start FastAPI / Uvicorn server
python -m uvicorn api.main:app --host 127.0.0.1 --port 8000
```
Open **[http://localhost:8000](http://localhost:8000)** in your browser!

## 🐳 Docker Deployment

Run the entire application in an isolated container:

```bash
# Build Docker image
docker build -t coldcase-detective-ai:latest .

# Run container on port 8000
docker run -d -p 8000:8000 --env GEMINI_API_KEY="your_api_key" coldcase-detective-ai:latest
```

## ☁️ Google Cloud Run Deployment

Deploy serverless in seconds with Google Cloud CLI:

```bash
# Set your Google Cloud project
gcloud config set project YOUR_GCP_PROJECT_ID

# Deploy directly to Cloud Run
gcloud run deploy coldcase-detective-ai \
  --source . \
  --platform managed \
  --region us-central1 \
  --allow-unauthenticated \
  --set-env-vars GEMINI_API_KEY="your_api_key_here",MOCK_MODE="0"
```

## 🧪 API Endpoints Overview

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/` | Serves the interactive Crime Board interface. |
| `GET` | `/api/cases` | Returns all 9 cold case dossiers with board elements and red strings. |
| `GET` | `/api/cases/{case_id}` | Retrieves full metadata and forensic evidence for a specific case. |
| `POST` | `/api/fetch-live` | Queries public endpoints (Wikimedia/FBI) for live crime data and photos. |
| `POST` | `/api/investigate` | Triggers the 6-agent collaborative reasoning pipeline on the active case. |
